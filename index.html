Booking · high traffic launch

Nintendo Switch 2 Pre-order

A pre-order site for a console launch, where thousands of fans hit the page at the same minute. It holds them in a fair queue, then lets each one book a unit at the dealer branch they pick.

  • Scalable booking platform with secure RESTful APIs, backend on EC2, static assets on S3.
  • AWS Lambda and Amazon SQS for event-driven, asynchronous work.
  • Front end in React 19 + Vite: waiting room with live queue rank, countdown and date guards per route, Thai/English i18n, Thai ID validation.
  • Branch dashboard with PIN login, quota tracking and Excel export. GitHub Actions deploys UAT and production.

Mobile app · internal tool

SynnexGo

An all-in-one staff app at Synnex Thailand. Employees clock in and out, request leave, log customer visits and approve documents from their phone.

  • React Native with Expo, built for Android and iOS through EAS, with over-the-air updates.
  • App launcher with favourites saved on the device, plus Thai/English and light/dark settings.
  • Time clock that records location, leave and overtime forms with attachments, and an Approval Center fed by the company API.
  • Push notifications through Expo and Firebase, with a small Node.js backend that sends them.
