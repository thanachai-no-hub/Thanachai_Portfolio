Agnos Hospital Middleware

A middleware API that lets hospital staff log in and search patients of their own hospital only. When a patient is not in the local database yet, it pulls the record from that hospital's HIS API.Middleware API ให้เจ้าหน้าที่โรงพยาบาลล็อกอินและค้นหาข้อมูลผู้ป่วยได้เฉพาะของโรงพยาบาลตัวเอง ถ้ายังไม่มีข้อมูลในฐานข้อมูล ระบบจะดึงจาก HIS API ของโรงพยาบาลนั้นมาให้

  • JWT login with access scoped per hospitalล็อกอินด้วย JWT และจำกัดสิทธิ์ตามโรงพยาบาล
  • Search still answers cleanly when the HIS fails or times outค้นหายังตอบกลับได้ปกติ แม้ HIS ล่มหรือตอบช้าเกินเวลา
  • Unit tests with in-memory fakes and httptest, no database neededUnit test ด้วย in-memory fake และ httptest ไม่ต้องใช้ฐานข้อมูลจริง
  • Docker Compose stack with a mock HIS, OpenAPI spec, and Swagger UIรันทั้งระบบด้วย Docker Compose พร้อม mock HIS, OpenAPI spec และ Swagger UI
