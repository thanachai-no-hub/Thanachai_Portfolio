# Thanachai Jankaew · Portfolio

Personal resume and portfolio site for Thanachai Jankaew, AIP Engineer and Full Stack Developer.

- Live M-Flow lane demo: vehicles pass a free-flow toll gantry and their plates are read
- Skill filter that highlights the roles and projects using each skill, and a Ctrl K quick-jump menu
- Clickable previews rebuilt from source: SynnexOnline (e-commerce), Nintendo Switch 2 pre-order, and the SynnexGo mobile app
- Light and dark theme

A single static page with no build step: open `index.html` in a browser, or serve the folder with any static host such as GitHub Pages or Vercel. Images used by the SynnexOnline preview live in `previews/`.
